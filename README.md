# 玄枢阁 · 天机串关演算

一个零第三方依赖的本地单页应用：从竞彩足球官方接口读取在售赛事，按农历月建、生辰干支、姓名五格、梅花本互变卦、体用生克与赔率数字生成娱乐性质的串关签文。

项目同时包含可直接由 Xcode 打开的 iOS 16+ 工程，详见 [`ios/README.md`](ios/README.md)。iOS 版使用原生 `URLSession` 取数，不需要本机 Node 服务。

## 启动

Windows 下双击 `启动.bat`，或使用：

```powershell
npm start
```

服务只监听 `127.0.0.1`，默认端口为 `8899`；端口占用时会自动顺延。建议使用 Node.js 18 或更高版本。

浏览器不能直连官方接口，页面会优先请求同源的 `api/matches`，由 `server.js` 完成服务端取数。

## 验证

```powershell
npm test
```

测试覆盖静态资源白名单、敏感文件隔离、CSP/压缩响应、跨域来源限制和非只读请求拦截。

## 可靠性设计

- 上游数据使用 15 秒内存缓存与单航班请求，避免并发重复取数。
- 上游失败时自动重试一次；近期缓存可在短时故障期间继续提供数据。
- 页面支持本地缓存降级，表单草稿保存在当前标签页的 `sessionStorage` 中。
- 所有上游字段与用户输入在进入 HTML 前均会转义。
- 静态资源采用显式扩展名白名单，隐藏目录、服务端源码和路径穿越请求均不可访问。
- 尊重系统的“减少动态效果”设置，并补齐状态播报、键盘焦点和移动端布局。

## 推演模型 v2

- 使用中国农历换算月建、日数与时支，不再直接把公历月日当作农历。
- 由出生日期生成干支日柱；出生时刻可选，填写后才补全时柱，不凭空推断。
- 姓名区分常见复姓，计算天、人、地、外、总五格与三才五行。
- 字库未收录的冷僻字使用固定近似规则，并在签文中明确标记，不静默当作准确笔画。
- 梅花时课同时生成主卦、互卦、变卦，并按动爻所在确定体卦与用卦。
- 单场评分由命格日主、时课体用、动爻场气、河洛数字、月建时气五层组成。
- 组合评分再校验五行生克、地支冲合、联赛数量与日期离散度。
- 相同输入及时课可复现；“再换一卦”由递增变数重新取象。
- 只给出评分最高的一组主推，不再生成或展示副卦。

点击起卦后会依次经过净心、校历、拆名、起卦、辨体、纳象、合串、封签八段仪轨，首个结果通常约 5 秒揭晓，重复问卦约 3 秒；启用“减少动态效果”时会缩短等待。

模型复杂度的提升只用于完善玄学娱乐体验和规则一致性，不代表具备预测比赛结果的能力。

本项目仅用于玄学娱乐，不构成投注建议。
